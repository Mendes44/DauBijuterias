DauBijuterias — Landing Page

Arquivos:
- index.html: estrutura da página
- styles.css: estilos e responsividade
- script.js: menu mobile e botão do vídeo

Como usar:
1. Mantenha os três arquivos na mesma pasta.
2. Abra o arquivo index.html no navegador.
3. Substitua 5500000000000 pelo número real do WhatsApp, com código do país e DDD.
4. Para adicionar o vídeo, substitua a seção .video-box por uma tag <video> apontando para o arquivo do vídeo.

Observação: as imagens atualmente usam os endereços das imagens enviadas no projeto. Para hospedagem externa, substitua os endereços https://ai.wrt/... por arquivos locais ou URLs públicas.
